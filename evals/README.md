# AgentOps Evaluation Framework (`evals`)

Evaluation datasets, test cases, and repeatable benchmarking harnesses for measuring agent planning, tool grounding, and report quality.

## Directory Layout
- `datasets/`: Standardized research corpuses (e.g., `competitor_corpus.json`) used for deterministic testing.
- `cases/`: Test case definitions specifying analytical research prompts and expected factual extractions.
- `baselines/`: Gold-standard reference plans, tool call sequences, and final report outputs.
- `reports/`: Generated evaluation scoring runs and citation coverage audits.
